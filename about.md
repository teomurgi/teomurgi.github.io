# About

He works in the **Smart Infrastructure Grid Software R&D (SI GSW R&D)** division, focusing on:

- **Domain Driven Design** — bounded contexts, aggregates, anti-corruption layers, context mapping
- **Agentic AI** — introducing autonomous AI agents in enterprise software R&D
- **Power Grid Management** — low voltage infrastructure, monitoring, and control systems
